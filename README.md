# JanaМен Digital HR

**[Открыть демосайт](https://digital-hr-6kln.onrender.com)**

Веб-приложение для сотрудников, руководителей и HR. В одном месте можно посмотреть профиль, оформить отпуск, пройти обучение и задать вопрос помощнику AI Jana.

Проект сделан для Challenge 02 Digital HR хакатона Jana Post × Terricon Valley.

## Как запустить

Нужны **Git** и **Docker Desktop**. Перед запуском откройте Docker Desktop. Python, Node.js и базу данных отдельно устанавливать не нужно.

**1. Скачайте проект:**

```bash
git clone https://github.com/bshakaryan/digital-hr.git
cd digital-hr
```

Если проект уже скачан, просто откройте терминал в его папке.

**2. Положите готовый файл `.env` в корень проекта**, рядом с `Dockerfile` и `compose.render.yaml`. Мы передадим его отдельно. Создавать или заполнять `.env` самостоятельно не нужно.

**3. Запустите одной командой:**

```bash
docker compose -f compose.render.yaml up --build -d --wait --wait-timeout 600
```

Первый запуск занимает несколько минут: Docker собирает приложение, создаёт базу и загружает демоданные.

**4. Откройте [http://localhost:10000](http://localhost:10000).**

Если в переданном `.env` указан `RENDER_WEB_PORT`, используйте этот порт вместо `10000`.

| Роль | Почта |

## Что реализовано

- **Личный кабинет:** профиль, остаток отпуска, свои заявки и уведомления. Кадровые поля доступны только для просмотра.
- **Отпуска:** расчёт дней, подача заявки, согласование руководителем и HR, история решений и списание дней после финального одобрения. Решение принимает человек.
- **Изменение планов:** отзыв и замена дат ожидающей заявки, запрос на отмену будущего согласованного отпуска с отдельным решением согласующего.
- **Календарь:** личные отпуска и общий календарь сотрудников с фильтром по подразделению.
- **Сотрудники:** поиск, подразделения и структура подчинения. Доступ к подробным профилям зависит от роли.
- **Jana Academy:** материалы курсов, тесты, адаптация, самостоятельная запись на доступные курсы, прогресс, XP и достижения. HR может создавать, публиковать и назначать курсы.
- **Аналитика обучения:** показатели по 34 демосотрудникам, завершённые и просроченные назначения, активность за 14 дней и учебные профили.
- **AI Jana:** ответы по загруженным PDF/DOCX со ссылками на источники, вопросы по материалам курса и личная история диалогов. В этом демозапуске помощник работает без внешней языковой модели.
- **Документы:** создание заявления на отпуск и демонстрация подписания или отказа через имитацию Documentolog.
- **Контроль:** уведомления, журнал действий с фильтрами и выгрузкой CSV, состояние интеграций и очередей передачи.

При первом запуске автоматически создаются **34 вымышленных сотрудника, 13 курсов, 177 учебных назначений и демокалендарь**. После наполнения каждому доступно 25 дней отпуска. Календарь Айданы оставлен свободным для ручной демонстрации. Повторный запуск сохраняет последующие заявки и учебный прогресс.

## Как устроен проект

**Frontend** — Next.js, React и TypeScript: страницы и интерфейс приложения. **Backend** — Python и FastAPI: API, права доступа, заявки и обучение. **PostgreSQL** хранит основные данные. Docker запускает всё необходимое.

```text
frontend/              — интерфейс
backend/app/           — сервер и логика приложения
backend/migrations/    — обновления структуры базы
backend/tests/         — автоматические проверки
knowledge_base_docs/   — документы для AI Jana и курсов
docs/                  — подробная документация
scripts/               — скрипты запуска и проверки
```

Интеграции с 1С:ЗУП и Documentolog работают через **демосервисы, имитирующие внешние системы**. Реальные базы компании и настоящая ЭЦП не подключены. Все сотрудники и учебные результаты вымышленные.

## Как остановить

В папке проекта выполните:

```bash
docker compose -f compose.render.yaml down
```

Основная база сохраняется. Для повторного запуска используйте команду из шага 3. Не добавляйте `-v` к команде остановки: это удалит базу. Состояние имитации подписания в этом варианте запуска временное.

Если приложение не запускается, посмотрите сообщения:

```bash
docker compose -f compose.render.yaml logs --tail=100 web
```
