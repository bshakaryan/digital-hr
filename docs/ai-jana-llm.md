# Опциональная генерация AI Jana

По умолчанию AI Jana отвечает прежними извлечёнными предложениями. Чтобы включить переформулировку, задайте **только в локальном `.env` или в секретах хостинга**:

```dotenv
LLM_PROVIDER=openai_compatible
LLM_API_KEY=<ключ выбранного провайдера>
LLM_API_URL=https://api.openai.com/v1/chat/completions
LLM_MODEL=gpt-4.1-mini
LLM_TIMEOUT_SECONDS=5
LLM_MAX_OUTPUT_TOKENS=200
```

Модель и HTTPS endpoint должны поддерживать формат [Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create) и быть доступны вашему аккаунту. Если уже задан `OPENAI_API_KEY`, можно использовать его вместо `LLM_API_KEY`; последний имеет приоритет. `LLM_PROVIDER=openai_compatible` всё равно включается явно. Для Docker Compose эти переменные передаются только сервису `backend`; в одиночном Docker Web Service задаются через настройки окружения хостинга. Настоящий ключ не вписывайте в `.env.example`, документацию, логи или Git.

Сервер сначала выполняет существующий поиск по доступным пользователю документам. Вопрос внутри курса ограничен прикреплёнными к назначенному курсу материалами. Провайдер получает вопрос и один выбранный текстовый фрагмент, без токена пользователя, профиля, других документов или истории чата. Модель не получает инструменты выполнения действий. Сервер проверяет полученный текст, выдаёт отказ при `NO_EVIDENCE`, сам добавляет маркер `[1]` и возвращает исходные метаданные фрагмента. При ошибке HTTP, тайм-ауте, неполном или небезопасном ответе автоматически возвращается извлекающий текст. Кадровых решений AI Jana не принимает.

Форма ответа API сохранена. Поле `mode: "extractive_demo"` является прежней совместимой меткой и **не указывает**, применялась ли генерация в конкретном ответе. Проверять фактическую формулировку следует по содержимому ответа и источнику. Включение режима не меняет права доступа и не делает синтетические материалы официальными правилами Jana Post. Перед публичным показом проверьте конкретный провайдер и модель на вашем ключе; автоматические тесты используют только HTTP-моки и не подтверждают доступность внешнего API или полную семантическую точность генерации.
