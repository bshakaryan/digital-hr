## Пределы проверки

Сборка и запуск Compose, миграция и функциональный сценарий на PostgreSQL теперь подтверждены на Linux ARM64 внутри Docker Desktop. Сборка Linux AMD64 в GitHub Actions, конкурентные гарантии/блокировки PostgreSQL и production-развёртывание отдельно не подтверждены. SQLite-тесты не подтверждают блокировки PostgreSQL; последовательный PostgreSQL smoke также не является конкурентным тестом.

Работа на физическом Android/iOS-телефоне не проверялась. Нет SSO, реальных персональных данных, реальных интеграций, генеративного AI и юридически значимых кадровых решений.
