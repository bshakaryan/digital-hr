Сборка и запуск Compose, миграции, функциональный сценарий и названные конкурентные сценарии PostgreSQL подтверждены на Linux ARM64 внутри Docker Desktop. Нагрузочная устойчивость, Linux AMD64 в GitHub Actions и production-развёртывание не подтверждены. SQLite-тесты сами по себе не доказывают PostgreSQL-блокировки; отдельный PostgreSQL-прогон выше проверяет ограниченные сценарии.

Работа на физическом Android/iOS-телефоне не проверялась. Нет SSO, реальных персональных данных, подключения к рабочей 1С/Documentolog, генеративного AI и юридически значимых кадровых решений. Демо-календарь ограничен 2026–2028; начисление остатка, рабочие годы и денежные отпускные не реализованы.
